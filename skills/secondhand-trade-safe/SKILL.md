# secondhand-trade-safe：二手交易安全流程

> 目标：付款这个动作发生之前，所有风险都已经上锁。
> 核心纪律：**钱不过手，货不离眼；先小人后君子，所有约定落文字。**

## 1. 何时使用

- 验机通过、价格谈妥，准备付款前 → 跑全流程
- 纠结"当面还是邮寄" → 跑第 2 节三选一
- 已经付款，担心售后 → 跑第 5 节 7 天计划

**输入**：交易方式偏好 + 商品信息 + 谈好的价格与退换约定。
**输出**：所选交易方式的操作清单 + 交易确认书（可直接发给卖家）。

## 2. 交易方式三选一

| 方式 | 适合 | 流程要点 | 风险点 |
|---|---|---|---|
| **当面验货**（最推荐） | 同城、金额 > 1000 | 公共场所见面→按验机清单测→现场转账→文字确认 | 别去对方家里/偏僻处；大额带朋友 |
| **平台验机服务** | 异地、数码产品 | 下单选"验机服务"→卖家先发货到平台→平台出报告→你确认后放款 | 看清验机项覆盖范围；验机费谁出先谈好 |
| **邮寄**（最后选） | 低价值、小件 | 走平台订单→卖家发货前拍打包视频→你开箱全程录像→保价 | 务必保价；开箱视频一刀不能剪 |

**选择建议**：能当面不当面是偷懒；异地数码优先平台验机；邮寄只用于丢了不心疼的价位。

## 3. 当面验货操作清单（可打印）

- [ ] 约公共场所（商场/地铁站），白天，告知朋友时间地点
- [ ] 带齐验机工具：满电手机、SIM 卡、耳机、充电宝、手电
- [ ] 按 `secondhand-inspect-guide` 清单逐项测，当场打勾
- [ ] 序列号现场再核对一遍（防止"狸猫换太子"：看的 A 机，给的 B 机）
- [ ] 谈好的瑕疵扣款当场确认最终价
- [ ] **现场转账**（平台/银行，备注"购买[品牌型号]二手"），不收现金（无记录）
- [ ] 卖家文字确认（微信发一遍交易确认书，对方回复"确认"）
- [ ] 拿走商品+配件+（如有）发票/购买记录

## 4. 交易确认书模板（复制即用）

```
二手交易确认书
卖方：[昵称/姓名]  买方：[昵称/姓名]  日期：[X月X日]

商品：[品牌型号+配置+颜色]
序列号：[XXX]（关键位打码：前X后X）
成色约定：[X成新；已知瑕疵：XXX]
配件：[充电器/包装盒/发票，有无逐项列]
价格：人民币 [X] 元，[平台订单/现场转账]支付
退换约定：[7天内发现暗病（非人为损坏）可退/可协商维修]；
  退换凭证以验机记录表+开箱/验机视频为准。

卖方确认：            买方确认：
（双方微信回复"确认"即生效）
```

**为什么必须有**：口头"有问题找我"=没说过。白纸黑字+双方确认，纠纷时这就是你的尚方宝剑。

## 5. 7 天暗病售后计划

| 天数 | 做什么 |
|---|---|
| D0 | 开箱/验机视频存档（云端备份，不过期） |
| D1-D3 | 按品类暗病清单复检（续航、发热、偶发故障），每天记录 |
| D4 | 还没问题→基本安全；有小问题→先跟卖家文字沟通留记录 |
| D7 | 最终确认：没问题→交易关闭；有问题→按确认书退换约定执行 |

**发现暗病时**：
1. 第一时间拍照/录像固定证据（别先拆机！拆了说不清）。
2. 微信文字联系卖家，附证据+确认书截图，要求按约定处理。
3. 卖家耍赖→平台纠纷仲裁（提交确认书+验机记录+证据链）；平台外交易→12345/报警（金额大时）。

## 6. 邮寄专项：打包与开箱

**发货前（卖家做，你盯）**：
- 要求卖家拍"打包视频"：商品序列号特写→装箱→封箱，一镜到底。
- 保价：按成交价足额保价，保费谈好谁出（建议买家出，买的是自己的安心）。
- 发顺丰/京东等可保价快递，单号发你。

**收货时（你做）**：
- 快递面单拍照（单号、保价金额）。
- **开箱全程录像，一刀不能剪**：从外包装完整度拍起，序列号特写，再开机验机。
- 外包装破损→当快递面开箱验货，异常直接拒收+联系卖家。

## 7. 平台纠纷仲裁实战（卖家耍赖时）

仲裁拼的不是谁有理，是谁证据全。按这个顺序准备材料：

1. **交易确认书**（第 4 节）：证明双方约定的成色、价格、退换条款——这是仲裁员先看的东西。
2. **验机记录表**（`secondhand-inspect-guide` 第 7 节）：证明你按清单验过，问题是"暗病"不是"你弄坏的"。
3. **开箱/验机视频**：一刀未剪的完整视频，证明问题在收货时已存在。
4. **沟通记录**：卖家承认瑕疵/拒绝处理的聊天截图（文字版，带时间）。
5. **第三方证据**：官方售后检测报告（"该机拆修过"）、维修报价单。

**仲裁话术模板**：
```
纠纷说明：本人于[X月X日]购买[品牌型号]，价格[X]元。
收货后按验机清单检测发现[具体问题]，附开箱视频（X分X秒处）与
官方检测报告。交易确认书约定"[复制退换条款原文]"。
诉求：[退货退款/部分退款X元]。
```
**时限**：发现暗病 24 小时内发起纠纷并固定证据；平台仲裁一般 3-7 天出结果，期间不要确认收货。

## 8. 账号/虚拟商品专项（高风险品类）

游戏账号、会员、课程等虚拟商品是二手纠纷重灾区，原则只有一条：**能不买就不买**。

- [ ] **找回风险**：账号可通过原始注册信息找回，"改密换绑"不等于安全。要求卖家提供原始注册信息并过户，不过户=随时被找回。
- [ ] **平台规则**：很多平台的用户协议禁止账号交易——买了可能被封号，钱货两空。
- [ ] **交易方式**：必须走支持虚拟商品担保的平台订单，私下转账=100% 风险自担。
- [ ] **换绑验证**：当场完成改密、换绑手机/邮箱、清除登录设备，72 小时内观察有无异地登录提醒。
- [ ] **合同**：交易确认书加一条"卖方承诺已移交全部注册信息，账号被找回则全额退款"。

实在要买：小额试水、大额走平台、留好"对方承诺过户"的文字证据。

## 9. 反模式（这些做法是错的）

1. **私下转账图省手续费** → 省几十块，丢几千块。平台订单是二手交易唯一的"保险"。
2. **"货到付款"** → 到付的不是货，是你的验货权——钱给了快递，货有问题找谁？
3. **外部链接/二维码付款** → 真交易都在 App 内完成，外部链接=钓鱼。
4. **先付全款再验机** → 顺序反了。验机→确认→付款，一步不能少。
5. **开箱不录像** → 邮寄纠纷没有开箱视频，平台仲裁直接判你输。
6. **确认书嫌麻烦不写** → 纠纷时"我当时说了"=没说。5 分钟写个确认书，省 5 天扯皮。

## 10. 自检与反馈

每次执行完本 skill，做一次轻量自检：

1. 是否按用户情况推荐了三选一之一并给了操作清单？→ "你看着办"不算推荐。
2. 交易确认书是否填好了商品/价格/退换三要素并提醒双方文字确认？
3. 7 天计划是否具体到每天做什么？

标准冒烟用例：见仓库根 `smoke_test.py`。

反馈渠道：以 `[QC] <一句话问题>` 为标题提交到 https://github.com/lhg-plugs/lhg-secondhand/issues，正文写清"输入 → 错误输出 → 期望输出"。
