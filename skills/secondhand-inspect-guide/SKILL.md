# secondhand-inspect-guide：分品类验机清单

> 目标：把"看着还行"变成逐项可验证的清单。二手交易最大的坑是暗病，验机是唯一的解。
> 核心纪律：**先查序列号（远程），再快检（5 分钟定生死），再细检（30 分钟），最后 7 天暗病排查。**

## 1. 何时使用

- 看中二手商品，准备当面验货/下单前 → 按品类取清单
- 卖家发来商品信息 → 先做第 2 节序列号远程查验
- 已经买到手 → 直接跳到第 7 节 7 天暗病排查

**输入**：品类 + 品牌型号 + 卖家描述。
**输出**：该品类的三档验机清单（可打印）+ 验机记录表。

## 2. 通用第一步：序列号远程查验（不花钱，先做）

交易前让卖家提供序列号/IMEI（关键位打码也可），走**官方渠道**查验：

- **手机/平板/电脑**：官网保修查询（输入序列号查保修到期日、是否为官换机）；官方客服电话可查激活锁状态。
- **相机/镜头**：官网注册查询；镜头查卡口触点氧化、镜片编号与机身是否对应。
- **查什么**：① 保修是否在期 ② 是否官换/官翻 ③ 有无挂失/被盗记录 ④ 激活锁/ID 锁是否解除。
- **红线**：卖家拒绝提供序列号 → 直接放弃，不要谈。

> 只用官方渠道，不推荐任何第三方"付费查档"（信息源不明，且可能泄露序列号）。

## 3. 手机验机清单（以智能手机为例）

### 5 分钟快检（决定付不付款）

- [ ] 开机正常，无 ID 锁/激活锁（恢复出厂设置后能进系统才算）
- [ ] 屏幕：纯色（白/黑/红/绿）下看亮点、坏点、烧屏；触摸全屏滑动无断触
- [ ] 摄像头前后都拍一张，闪光灯亮
- [ ] 打电话：听筒+麦克风+扬声器（拨 10086 听 10 秒）
- [ ] 指纹/面容解锁录入并解锁成功
- [ ] 插 SIM 卡：信号、通话、移动数据

### 30 分钟细检

- [ ] 电池健康度（系统设置里看；低于 85% 按更换成本砍价）
- [ ] 所有按键（音量/电源/静音键）手感与功能
- [ ] 充电口：插拔充电正常，无松动；无线充电试一下
- [ ] 蓝牙/WiFi/GPS/NFC 逐项连接测试
- [ ] 机身：边框磕碰、后盖缝隙（拆修过的缝隙不均匀）、螺丝有无拧痕
- [ ] 进水指示标（卡托内/官网查位置）：变红=进过水

### 7 天暗病排查

- [ ] 续航实测：满电正常使用一天，掉电曲线是否断崖
- [ ] 发热：刷视频 30 分钟是否烫手（异常发热可能是主板暗病）
- [ ] 偶发重启/闪退：每天记录，3 天内出现 2 次以上→找卖家
- [ ] 信号：在电梯/地下室对比同运营商手机

## 4. 笔记本电脑验机清单

### 5 分钟快检

- [ ] 开机进系统，无 BIOS/系统密码锁
- [ ] 屏幕纯色检查（坏点、漏光，黑色下看漏光最明显）
- [ ] 键盘逐键敲一遍（含组合键），触控板多点触控

### 30 分钟细检

- [ ] 电池：系统报告看循环次数与健康度（Mac 看"电池-循环计数"）
- [ ] 所有接口：USB/充电口/HDMI/耳机孔逐一插拔
- [ ] 风扇：跑个 4K 视频听风扇，有无异响；出风口是否烫手异常
- [ ] 硬盘：查通电时间与健康度（SMART 信息）
- [ ] 摄像头/麦克风/扬声器
- [ ] 螺丝：底盖螺丝有无拧痕（拆修痕迹）

### 7 天暗病排查

- [ ] 高负载 1 小时（视频剪辑/跑分）：是否蓝屏、死机、过热降频
- [ ] 睡眠唤醒：合盖/开盖 20 次，偶发无法唤醒=主板/内存暗病信号
- [ ] 电池续航实测 vs 卖家说法

## 5. 相机/镜头验机清单

### 快检

- [ ] 快门次数（官网/第三方软件读；机械快门寿命有限，次数越高越要砍价）
- [ ] 各档快门+光圈试拍，照片放大看：坏点、霉斑、进灰
- [ ] 自动对焦：近/远各拍 3 张，是否跑焦

### 细检

- [ ] CMOS：小光圈拍白墙/天空，看霉点、划痕（传感器霉=大修）
- [ ] 镜头：强光手电逆光看镜片，霉丝、气泡、划痕；对焦环/变焦环阻尼顺滑
- [ ] 卡口触点：氧化、磨损程度；卡口有无旷量
- [ ] 热靴、翻转屏排线（翻转 20 次看有无黑屏闪断）

### 暗病

- [ ] 连续拍摄 200 张：是否过热关机、写入报错
- [ ] 高 ISO 夜景：坏点/热噪是否异常多

## 6. 耳机与奢侈品箱包

**耳机**：
- [ ] 序列号官网查保修；左右耳分别试听（偏音是最常见的暗病）
- [ ] 降噪/通透模式切换；充电仓触点、合盖磁吸
- [ ] 7 天：续航实测（标称 6 小时实际 3 小时=电池衰减）

**奢侈品箱包**：
- [ ] **本清单不做真伪鉴定**：贵重箱包请走平台鉴定服务或专柜验货
- [ ] 五金刻字清晰度、走线针脚均匀度、序列号/身份卡与包内标一致性
- [ ] 边角磨损、内衬污渍、手柄开裂（维修成本极高，逐项拍照砍价）

## 7. 验机记录表（复制即用）

```
商品：[品牌型号]  卖家：[昵称]  验机日期：[X月X日]
| # | 项目 | 结果 | 备注 |
|---|---|---|---|
| 1 | 序列号官方查验 | ✅/❌ | 保修至X年X月 |
| 2 | ... | | |
结论：[通过/有瑕疵砍价X元/放弃]
卖家确认（文字）：
```

验完让卖家**文字确认**结论（微信发一遍"今天验机结果如下…确认请回复"），这是 7 天退换的证据。

## 8. 反模式（这些做法是错的）

1. **"看着成色不错就直接转钱"** → 成色≠功能，暗病都长在看不见的地方。
2. **卖家说"支持验机"但只给 5 分钟** → 5 分钟只够快检，细检被压缩=有东西不想让你看。
3. **跳过序列号查验** → 官换机、挂失机、ID 锁机，全栽在这一步。
4. **验机时不好意思较真** → 现在不好意思的每一秒，都是退换时吵架的一小时。
5. **"兄弟价，先转钱再发货，包你满意"** → 满意不满意，钱转出去那一刻就由不得你了。
6. **第三方"付费查档"** → 信息源不明还可能泄露你的设备信息，只用官方渠道。

## 9. 自检与反馈

每次执行完本 skill，做一次轻量自检：

1. 是否按"序列号→快检→细检→暗病"四步给了清单？→ 缺一步都不算完整。
2. 每个检查项是否写了"怎么测+什么算通过"？→ 只列名词不算清单。
3. 是否给了验机记录表并提醒卖家文字确认？

标准冒烟用例：见仓库根 `smoke_test.py`（fixtures 坏/好对照 + skill 结构检查）。

反馈渠道：以 `[QC] <一句话问题>` 为标题提交到 https://github.com/lhg-plugs/lhg-secondhand/issues，正文写清"输入 → 错误输出 → 期望输出"。
