# secondhand-price-check：成色定价框架

> 目标：给二手商品算出"合理区间"，而不是凭感觉砍价。
> 核心纪律：**市场价锚必须来自用户自己的调研（5 个成交价），AI 不编任何价格数字。**

## 1. 何时使用

- 看中商品，卖家报价拿不准贵不贵 → 跑全流程
- 准备砍价，不知道从多少开始谈 → 跑第 2+5 节
- 想卖自己的闲置，不知道挂多少 → 同样适用（把"买家"换成"你"）

**输入**：品类 + 品牌型号 + 成色描述 + 卖家报价 + 用户调研的市场价区间。
**输出**：合理价格区间 + 报价位置判断 + 砍价方案。

## 2. 第一步：定锚（教用户查，AI 不代查不编数）

1. 去主流二手平台搜**同品牌同型号同配置**，看**已成交**（不是挂牌价）至少 5 个。
2. 剔掉最高最低，剩下取区间，记为 [L, H]。
3. 全新国行价做 sanity check：9 成新二手通常为全新 55%-75%（品类差异大，只用来发现离谱值）。
4. 用户确认区间后，AI 才往下算。用户没查 → 先给"怎么查"的步骤，不许跳过。

**为什么必须用户自己查**：价格是谈判筹码，筹码必须是你亲手拿到的才硬。AI 编的数字你拿去砍价，被卖家反问一句就露馅。

## 3. 第二步：成色折价框架

以市场价区间中位数 M 为基准，逐项调整：

| 维度 | 调整方法 |
|---|---|
| 成色 9 成新 | 基准（M 附近） |
| 成色 8 成新 | M × 0.85 左右 |
| 成色 7 成新及以下 | M × 0.7 以下，且重点怀疑暗病 |
| 电池健康 < 85% / 快门过半 | 直接扣更换/折旧成本（查官方维修价） |
| 配件缺失（充电器/包装/发票） | 每缺一项扣 50-200（按品类） |
| 换屏/换电池/拆修史 | 在成色基础上再扣 15%-30% |
| 已过保 | 小幅扣 5% |
| 发票/购买记录齐全 | 可上浮 5%（来源可信=风险低） |

**输出格式**（可直接打印/复制，拿着去砍价）：
```
市场价区间：[L, H]（用户调研，5 个成交价）
成色调整后合理区间：[L', H']
卖家报价 X 元 → 落在区间的 [低位/中位/高位/超出]
建议目标价：Y 元；walk-away 线：Z 元（超 Z 放弃）
```

## 4. 第三步：杀猪话术识破（对照交易信息逐条点破）

| 话术 | 翻译 | 反制 |
|---|---|---|
| "全新未拆封，亏本出" | 多为翻新/官换冒充，或空单诈骗 | 查序列号激活状态；价格+全新+私下交易叠加→放弃 |
| "不退不换，信我就买" | 把暗病风险全甩给你 | 坚持验机+平台交易；拒绝→放弃 |
| "好几个买家在谈，先付定金留货" | 逼单，买家多半不存在 | "那你卖给他们吧"，真想买就报实价 |
| "到手刀"（买家压价） | 你是卖家时遇到：对方现场挑刺压价 | 提前定 walk-away 线，现场不临时改价 |
| "平台扣费，走微信便宜 200" | 私下转账=裸奔 | 省 200 冒丢 2000 的风险，不值 |
| "女生自用，几乎没用过" | 话术模板，信 3 成 | 一切以验机结果为准，故事不加分 |

## 5. 第四步：砍价三档话术（复制即用）

**① 锚定式**（有理有据）：
"同款上周成交了 X、X、X（发截图），都在 [L,H] 区间。你这台[成色/配件情况]，我出 Y，今天就能定。"

**② 瑕疵式**（验机后用）：
"刚验了，[电池 82%/边框磕碰/缺充电器]，这几项我得花 [X] 块处理，Y 你看行不行？"

**③ 打包式**（一口价）：
"配件不全，我也不折腾了，Y 一口价，现在转账，你省心我也省心。"

**底线纪律**：
- walk-away 线写在纸上，现场不临时改。
- 卖家说"还有别人出更高"→ "那恭喜，你卖他吧。"（真有别人，他不会跟你废话。）
- 砍价成功→落文字确认（价格+成色+退换约定），再付款。

## 6. 影响保值率的 5 个因素（买前看跌幅，卖前看时机）

1. **品牌**：保值率第一驱动。二手市场认"硬通货"品牌，同一成色差价可达 30% 以上。
2. **发布时间**：新品发布前后 1 个月是旧款价格波动最大的窗口——买旧款等发布会后，卖旧款赶发布会前。
3. **配置**：丐版最保值，顶配贬值最快（"配置溢价"在二手市场几乎不被承认）。
4. **成色与配件**：原装配件齐全+发票，成交速度快一倍；裸机要做好被砍价的准备。
5. **维修史**：拆修史是保值率杀手，买时要问清，卖时要诚实（隐瞒=纠纷）。

**时机口诀**：买，等新品发布后 1 个月；卖，赶新品发布前 1 个月。逆周期操作，一出一入能差出 15%。

## 7. 三种出手方式对比（你卖闲置时）

| 方式 | 价格 | 省心度 | 适合 |
|---|---|---|---|
| 自己挂二手平台卖 | 最高（市场价） | 低（要拍照、回消息、防到手刀） | 不差时间、想卖高价 |
| 平台官方回收 | 中（约为市场价 70%-85%） | 高（上门取件、当场打款） | 怕麻烦、怕纠纷 |
| 以旧换新抵扣 | 低（通常最低） | 最高（买新机时顺手抵） | 换新机且不在乎差价 |

没有最优，只有最适合：时间贵就选回收，钱紧就自己挂。

## 8. 卖闲置反向应用（你当卖家时）

- 定价：按第 3 节框架算你的合理区间，挂牌取 H'（留砍价空间）。
- 描述：成色实话实说+多角度照片+序列号可查，诚实描述的成交速度比"全新"话术快。
- 防"到手刀"：提前想好最低价，现场买家挑刺→"价格已经按这个瑕疵定了，不再让"。
- 只走平台交易，不收私下转账（保护你自己：买家事后纠纷平台有记录）。

## 9. 卖家类型识别（同样的话，对不同的人说）

| 类型 | 特征 | 策略 |
|---|---|---|
| **急出型** | "急出""搬家""回血"，描述详细、回复快 | 直接报目标价，爽快成交；别反复拉扯，急出型最烦墨迹 |
| **试探型** | 挂高价，"可小刀"，不急不慢 | 用成交截图锚定，慢慢磨；不接受就等，他大概率会降价 |
| **商贩型** | 多件在售、话术专业、"不议价" | 别 waste 时间砍价，重点验机；商贩的货源杂，暗病概率高 |
| **故事型** | 大段故事、"女生自用""公司奖品" | 故事打 3 折听，验机打 12 分精神；故事越长，越要查序列号 |

**通用原则**：先判断类型再选话术。对急出型用"一口价今天定"，对试探型用"截图锚定慢慢磨"，对商贩型把精力放验机上，对故事型只信验机报告。

## 10. 反模式（这些做法是错的）

1. **用挂牌价当市场价** → 挂牌价是卖家的愿望，成交价才是市场。差 20% 很常见。
2. **"看着便宜就先下单"** → 便宜+急=坑。先验机再付款，顺序不能反。
3. **砍价只砍一口，不给理由** → "便宜 500"会被无视；"电池 82% 换电池要 300"才有杀伤力。
4. **walk-away 线现场上调** → 上头是二手交易最大的成本。写下来，超线就走。
5. **信故事不信验机** → "女生自用""公司年会奖品"都是话术，验机报告才是事实。
6. **AI 报的"市场价"直接拿去用** → 本 skill 不编价格；拿 AI 编的数字去砍价，等于拿假钞买东西。
7. **砍价时暴露"我很想要"** → "我找了好久就等这台"一出口，价格就砍不动了。冷静是砍价最大的筹码。

## 11. 自检与反馈

每次执行完本 skill，做一次轻量自检：

1. 市场价锚是否来自用户调研（5 个成交价）？→ AI 编的数字一律不算。
2. 是否输出了"合理区间+报价位置+目标价+walk-away 线"四件套？
3. 砍价话术是否给了三档且可直接复制？

标准冒烟用例：见仓库根 `smoke_test.py`。

反馈渠道：以 `[QC] <一句话问题>` 为标题提交到 https://github.com/lhg-plugs/lhg-secondhand/issues，正文写清"输入 → 错误输出 → 期望输出"。
