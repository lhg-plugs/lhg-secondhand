# /lhg-secondhand:secondhand —— 二手交易全流程避坑

用户输入在 `$ARGUMENTS` 中：`[商品信息文本文件路径] [--market-low 低价 --market-high 高价]`。没给文件就先问用户粘贴商品描述/聊天记录（存为临时文件再扫）。

## 流程（加载 skill 顺序）

### 1. 交易信息风险扫描（必做，先跑脚本）

```bash
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/audit/trade_audit.py --target <信息所在目录> --format text --market-low <低> --market-high <高>
```

- 市场价区间让用户自己先查（同品类二手平台近期成交价 5 个链接取中位数区间），不许替用户编市场价。
- blocker（不退不换/私下转账/外部链接付款）：直接判"别碰"，给放弃理由。
- warning（信息缺项/价格偏离）：转成"向卖家追问清单"。

### 2. 验机（加载 `secondhand-inspect-guide`）

按品类输出可打印验机清单：手机 / 笔记本电脑 / 相机 / 耳机 / 奢侈品箱包，选用户要买的品类。
每项清单分三档：**到手 5 分钟快检**（决定要不要付款）、**深度 30 分钟细检**（回家复检）、**暗病排查**（7 天内）。

### 3. 价格评估（加载 `secondhand-price-check`）

- 成色定价框架：全新价 → 按成色/年限/配件齐全度打折的计算表。
- 杀猪话术识破：对照脚本扫出的高危话术逐条点破。
- 输出"心理价位区间 + 砍价话术 +  walk-away 线"（超过多少就放弃）。

### 4. 交易安全（加载 `secondhand-trade-safe`）

- 当面验货流程 / 平台验机流程 / 邮寄流程三选一，给步骤清单。
- 交易确认书模板（商品信息+成色+价格+退换约定，双方文字确认）。
- 售后 7 天暗病排查计划。

### 5. 输出《二手交易避坑报告》

1. 风险总览：blocker X / warning Y，一句话结论（可买 / 追问后再定 / 别碰）
2. 向卖家追问清单（信息缺项转成的问句，可直接复制发给卖家）
3. 验机清单（可打印）
4. 价格评估与砍价话术
5. 交易流程与确认书模板

## 硬规则

- 市场价区间必须来自用户或用户确认的调研，不许编数字。
- 有 blocker（私下转账/不退不换/外部链接）→ 结论只能是"别碰"，不许说"小心点就行"。
- 不许替用户判断"这个卖家是骗子"；只能说"命中 X 条高危信号，建议放弃"。
